The release

The 2026-07-28 specification makes stateless operation the default shape of modern MCP. Each request carries the protocol metadata a server needs, so infrastructure can route work without relying on session affinity.

  • Stateless protocol core for simpler scaling behind gateways and load balancers.
  • Multi round-trip requests for elicitation and other interactive flows.
  • First-class extensions with explicit capability negotiation.
  • Routing and cache metadata that works with ordinary web infrastructure.
